# Demo signal bundle

This folder contains 10 selected CTU-UHB CTG Database recordings used by the
deployed Streamlit demonstration:

- `1198`, `1035`, and `1488`: Phase 5 true-positive, false-positive, and
  false-negative case studies
- `1127`, `1495`, `1156`, `1143`, `1065`, `1262`, and `1002`: additional
  high-, medium-, and low-score records for browsing

This is **not the full CTU-UHB dataset**. The complete dataset remains a local
download for research reproducibility and is excluded from the repository.
The selected files are public, de-identified research records from the
CTU-UHB CTG Database on PhysioNet. Please retain the dataset attribution and
licence when redistributing this demo bundle.
